# 园林设计通论

知识类型：专业必修课 │ 覆盖范围：东西方设计理论 │ 核心框架：要素 → 原则 → 空间

## 一、课程概述

园林设计通论不限定于某一地区或时期，而是提炼跨文化的设计方法。无论是中国园林的"借景"、日本茶庭的"露地"、英国风景园的"如画"、还是现代景观的"生态设计"，底层逻辑共享同一套设计语言。

## 二、园林设计的构成要素

### 基础六要素

| 要素 | 作用 | 处理手法 |
|------|------|---------|
| 地形 | 空间骨架 | 平地/坡地/台地/山谷，排水+视景 |
| 水体 | 动态生命 | 静水/流水/跌瀑/喷泉，倒影+声景 |
| 植物 | 四季变化 | 层次/色彩/质感/季相，乔木/灌木/地被 |
| 路径 | 空间组织 | 直线（正式）/曲线（自然），材料过渡 |
| 构筑物 | 功能+定义 | 亭/廊/架/桥/墙/栏杆 |
| 节点 | 空间焦点 | 雕塑/坐凳/火塘/观景台 |

### 硬质材料（Hardscape）与软质（Softscape）
- **硬质**：铺装（石材/木材/透水砖/砂砾）、墙体、结构
- **软质**：植物（树木/灌木/草花/草坪）、土壤、水的动态部分

## 三、跨文化设计原则

| 原则 | 中国园林 | 日本园林 | 西方园林 |
|------|--------|---------|---------|
| 主次分明 | 主景突出 | 枯山水主石 | 焦点树/雕塑 |
| 对比协调 | 虚实/疏密/明暗 | 砂纹vs苔面 | 开放草坪vs密林 |
| 节奏韵律 | 曲径通幽 | 飞石序列 | 林荫道 |
| 尺度比例 | 小中见大 | 缩景（盆栽美学） | 黄金分割 |
| 空间的连续与过渡 | 框景/对景 | 露地→茶室 | 室内外过渡 |

## 四、空间设计手法

### 视线控制
- **开敞**：大草坪/湖面（英国自然风景园）
- **封闭**：林下空间/绿篱围合（规则式花园）
- **半开敞**：树冠覆盖+视线通透（林间小径）
- **框景**：用门/窗/植物限定视野（中国园林核心手法）

### 轴线与路径
- **规则式**：主轴线+对称副轴（法国勒诺特尔式）
- **自然式**：蜿蜒路径引导发现（英国风景园、中国曲径）
- **渐进式**：台阶+平台+台地（意大利台地园）

### 序列设计
- **开始**：入口——暗示即将进入另一个世界
- **发展**：路径——序列展开，重复与变化
- **高潮**：主景——视线豁然开朗/到达核心场所
- **结尾**：收束——静谧气氛，回味空间

## 五、东西方重要设计理论

### 中国——《园冶》（计成，1631）
- 世界最早的造园专著
- "虽由人作，宛自天开"——造园最高原则
- "三分匠，七分主人"——业主审美决定品质
- "借景"的全面论述（远借/邻借/仰借/俯借/应时而借）

### 西方——《建筑十书》（维特鲁威，前1世纪）
- 奠定西方园林的轴线+对称基础
- Firmitas（坚固）、Utilitas（适用）、Venustas（美观）

### 西方——勒诺特尔式（André Le Nôtre, 1613-1700）
- 凡尔赛宫园林——透视法+大尺度+花坛+水渠
- 特点：无限延伸的轴线，象征对自然的绝对掌控

### 现代——《设计结合自然》（Ian McHarg, 1969）
- 生态规划方法论：将自然过程作为设计依据
- 叠图分析（overlay mapping）——GIS前身

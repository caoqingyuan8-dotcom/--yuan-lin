# 日本园林史

知识类型：专业必修课 │ 覆盖时段：飞鸟时代→现代 │ 核心框架：五种园林类型 + 禅宗影响

## 一、课程概述

日本园林源于中国，但走出了一条截然不同的路。它将中国园林的"山水之美"转化为"禅寂之美"——用极致的简素表达宇宙的秩序。核心是**枯山水**（karesansui）——不用水而表现水的艺术。

日本园林与茶道、花道、建筑、禅宗紧密共生，是"文化的总和"。

## 二、发展脉络

### 飞鸟·奈良时代（592-794）：池泉庭园起源
- **背景**：佛教传入、遣唐使带回中国造园技术
- **形式**：池泉舟游式——大型池塘+中岛+石桥，乘船游赏
- **案例**：平城宫东院庭园（奈良，复原）、法隆寺
- **特征**：模仿唐风，初具规模

### 平安时代（794-1185）：寝殿造庭园
- **建筑**：寝殿造样式——主人居所+对屋+中廊
- **园林**：南池——寝殿前南向展开大面积水池
- **文化**：贵族文学（《源氏物语》）大量描写庭园场景
- **案例**：毛越寺庭园（岩手，现存平安净土庭园代表）
- **创新**：净土式庭园——以极乐净土为蓝本的宗教庭园

### 镰仓·室町时代（1185-1573）：枯山水诞生
- **转折**：禅宗（临济宗）传入，武家文化兴起
- **核心**：梦窗疏石——枯山水奠基人（天龙寺、西芳寺）
- **形式**：白砂象征大海，石头象征岛屿、山脉、虎渡子
- **案例**：
  - 龙安寺石庭（京都）——15块石头在枯山水砂纹中，无论从哪个角度只能看到14块
  - 大德寺大仙院（京都）——室町枯山水代表作
  - 银阁寺（京都）——银沙滩+向月台，枯山水与茶庭过渡

### 桃山·江户时代（1573-1868）：茶庭与回游式
- **茶庭（露地）**：千利休将茶道空间扩展为庭园——飞石、石灯笼、蹲踞、植栽矮树
- **回游式**：池泉回游式庭园——沿池环绕游赏，借景远处山峦
- **案例**：
  - 桂离宫（京都）——回游式茶庭最高杰作
  - 兼六园（金泽）——日本三大名园之一，"宏大、幽邃、人力、苍古、水泉、眺望"六胜
  - 后乐园（冈山）——日本三大名园
  - 偕乐园（水户）——日本三大名园

### 明治至今（1868-现代）：融合与转型
- **近代**：引入西方公园概念，庭园向公众开放
- **现代**：日本当代景观设计（枡野俊明等）将枯山水语汇转化为现代设计语言
- **案例**：足立美术馆（岛根）——连续20年日本第一庭园奖

## 三、五种庭园类型

| 类型 | 年代 | 特征 | 代表作 |
|------|------|------|--------|
| 池泉舟游式 | 飞鸟·奈良 | 大池+划船游赏 | 平城宫东院 |
| 净土式 | 平安 | 极乐净土意象+水池 | 毛越寺、平等院 |
| 枯山水 | 室町 | 石+砂，无水表现水 | 龙安寺、大德寺大仙院 |
| 茶庭（露地） | 桃山 | 飞石+石灯笼+蹲踞 | 桂离宫、武者小路千家茶室 |
| 回游式 | 江户 | 绕池游赏+借景 | 兼六园、后乐园 |

## 四、核心元素

| 元素 | 日语 | 含义 |
|------|------|------|
| 枯山水 | karesansui | 以砂代水，以石代山 |
| 飞石 | tobi-ishi | 步道散置的石板 |
| 石灯笼 | ishidōrō | 石制灯笼，原为茶庭照明 |
| 蹲踞 | tsukubai | 茶庭洗手钵，弯腰使用以示谦卑 |
| 砂纹 | suna-mon | 用耙子划出的波纹图案 |
| 借景 | shakkei | 将远山纳入庭园构图 |
| 垣根 | kakine | 竹篱笆，划分空间的边界 |

## 五、关键人物

| 人物 | 时代 | 贡献 |
|------|------|------|
| 梦窗疏石 | 镰仓·室町 | 枯山水奠基人，天龙寺、西芳寺 |
| 千利休 | 桃山 | 茶道大成者，茶庭（露地）体系确立 |
| 小堀远州 | 江户 | 远州流茶道，兼六园设计 |
| 重森三玲 | 昭和 | 现代枯山水，东福寺方丈庭园 |
| 枡野俊明 | 现代 | 当代枯山水大师，跨界建筑设计 |

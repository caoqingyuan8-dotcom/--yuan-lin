# 中国园林史：三千年山水理想的演变

## 课程定位

**知识类型：专业必修课** | **覆盖时段**：先秦→近现代 | **核心框架**：六大时代 + 四大要素 + 造园手法

中国园林史不是一串建筑和园名的编年排列。它是一部"理想栖居方式"的演变史——每一座园林背后，都站着一个人或一群人关于"应该怎么活"的答案。

三千年的演变有一条清晰的逻辑线：
- **功能**：围猎 → 游赏 → 隐居 → 精神栖居
- **审美**：宏大壮丽 → 模拟自然 → 写意自然 → 精致与综合
- **哲学**：礼制秩序 → 天人合一 → 禅道心境 → 文人自觉

这三个维度并非各自独立地线性推进，而是层层叠加、彼此缠绕——新的阶段从来不是简单地取代旧的，而是在原有基础上叠加了新的层次。

## 第一部分：六大时代——园林的演变脉络

### 一、先秦：囿台时代（约前1100—前221）

**从"有用"的土地到"有意"的空间**

"囿"是先秦园林的原型——圈起一片山林水泽，放养禽兽，供帝王狩猎。这还不是"造园"，而是把自然的一部分圈起来使用。但"圈起来"这个动作本身就是关键：它标志着人对自然的态度从"完全被动利用"转向"主动划定领域"。

"台"是另一种源头——人工堆筑的高台，用于祭祀、观天、通神。台是中国人最早的"建筑"，也是最早的"竖向空间营造"。周文王的灵囿、灵台、灵沼（《诗经·大雅·灵台》有载）是已知最早的大型园林记载。

**先秦的深远影响**：囿的围合观念 → 后世园林的"边界意识"；台的登高望远 → 后世园林的"借景"意识；井田制的沟洫体系 → 为后世理水提供了技术原型；灵沼（人工水体）→ 中国园林理水的起点。

**代表**：文王之囿（灵囿、灵台、灵沼）· 今西安西南灵台遗址

### 二、秦汉：皇家园林的宏大格局（前221—220）

**大一统帝国对"无限空间"的欲望**

秦始皇统一中国后，园林的尺度被帝国野心彻底放大。上林苑是汉代皇家园林的巅峰——汉武帝在秦旧苑基础上扩建，跨今西安、咸阳、蓝田五县，是中国历史上最大的皇家园林。

但秦汉园林最重要的贡献不是"大"，而是一个影响中国园林两千年的母题：**一池三山**。建章宫太液池中堆筑蓬莱、方丈、瀛洲三座仙山，象征东海中的三座神山。此后凡皇家园林必有一池三山——北京颐和园的昆明湖中有南湖岛、治镜阁岛、藻鉴堂岛，正是这个母题的最后一轮回响。

**秦汉的特征**：规模宏大（帝国气派的物化）、方士神仙思想主导（求仙、长生）、建筑群密集（宫苑一体）、山水尚处于"背景"地位（建筑才是主角）。

**代表**：上林苑（已毁）、建章宫太液池（遗址）

### 三、魏晋南北朝：自然山水园的诞生（220—589）

**"归去来兮"——文人发现山水**

这是中国园林史上最深刻的转折。政治动荡、社会混乱→士人避世归隐→亲近自然不再是帝王的特权，而成为文人安顿生命的方式。

核心变化：园林的"观看方式"变了。汉代园林是"征服"自然的（宏大、秩序），魏晋园林是"欣赏"自然的（真实、亲切）。石崇金谷园、陶渊明的归园田居，园林成了一个人可以"生活进去"的地方。陶渊明"采菊东篱下"不是审美姿态，是生活方式本身。

**文化背景**：玄学盛行（"越名教而任自然"）、佛教传入（"空"与"寂"的审美意识）、山水诗兴起（谢灵运是中国第一位山水诗人）、文人直接参与造园（园子开始有了"作者"）。

**魏晋的遗产**：奠定了中国园林"虽由人作，宛自天开"的核心美学；自然山水从"背景"变成"主体"；园林与隐逸文化深度绑定。

**代表**：石崇金谷园（洛阳，已毁）、陶渊明归园田居（庐山，已毁）

### 四、隋唐：文人园林的成熟（581—907）

**诗画入园——园林成为可居的诗歌**

唐代是中国文化的黄金时代，园林也达到了一个新的高度。皇家园林方面，隋西苑是人工山水的大规模工程，唐大明宫太液池延续了一池三山的传统。但真正推动园林美学质变的是文人私家园林。

王维的**辋川别业**是标志性事件——他把自己在蓝田的别业画成《辋川图》，每一处景致配一首诗。诗画入园从此成为中国园林的核心基因：园林不只是"造的"，还是"写的""画的"。

白居易的**庐山草堂**进一步推动了"适意"理论——园林的价值不在于多大、多豪华，而在于是否"适合我的心意"。这个"适意"理论成为中国园林审美的一个重要转向：从"客观的好看"转向"主观的舒适"。

**唐代的特征**：诗、画、园三者的深度融合；"壶中天地"的空间意识出现（在小空间中创造无限感）；文人参与造园成为常态。

**代表**：王维辋川别业（已毁，有《辋川图》传世）、白居易庐山草堂、隋西苑（洛阳）、唐大明宫太液池（西安）

### 五、宋元：写意园林的巅峰（960—1368）

**以少胜多——小空间里的无限世界**

宋代园林在唐代的基础上更进一步：从"师法自然"走向**"写意自然"**。不是在园中再现自然的形状，而是用有限的物象唤起无限的想象——这是中国园林从"再现"到"表现"的完成。

宋徽宗修建的**艮岳**是中国古典园林登峰造极之作——集叠山、理水、建筑、花木之大成，规模虽不及上林苑，但艺术高度远超前人。艮岳是中国园林史上的一座分水岭：它证明了园林可以像绘画一样"写意"——不需要大，不需要真山水，人造的咫尺山林足以唤起对天地万物的感受。可惜艮岳随着北宋灭亡被毁。

宋代还留下了苏州**沧浪亭**——现存苏州园林中最古老的一座（始建于北宋），以"苍古"的气质成为后世文人园林的精神源头。

元代延续宋代余韵，文人画与园林的融合进一步加深。

**宋代的特征**：空间尺度变小（城市密集→小园成为主流）；意境密度增高（每一处景都要"有说法"）；以少胜多的美学成熟；叠山技法走向极致（艮岳是最高成就）。

**代表**：艮岳（北宋开封，已毁）、沧浪亭（苏州，现存最古）

### 六、明清：集大成与黄金期（1368—1912）

**江南文人的精致 + 皇家园林的恢弘**

明清是中国园林最后的黄金期，也是技术最成熟、流派最丰富的时期。

**江南私家园林**：苏州园林的黄金期。拙政园（明）、留园（明）、网师园（宋始建、清重建）、环秀山庄（清）——每一座都是中国园林的巅峰之作。江南园林的特点是：空间不大，但密度极高——步步有景、处处有画、每一转弯都是一个新的构图。

**北方皇家园林**：清代皇帝多次南巡，将江南造园技艺引入北方。颐和园是最后一座大型皇家园林，吸收了江南私家园林的造园手法。圆明园被西方称为"万园之园"——集中国园林之大成，兼收西洋建筑元素，可惜在1860年被毁。

**理论集成**：计成《园冶》（1631年刻印）——中国第一部系统的造园理论著作。名匠：张涟（张南垣）——明末清初叠山大师，主张"截溪断谷"的写意叠山法。

**清代的特征**：江南文人园追求精致雅致（以"雅"为最高标准）；皇家园林吸收江南手法，形成"南北合流"；造园理论成熟、总结性著作出现；园林从私密走向公共。

**代表**：拙政园、留园、网师园、环秀山庄（苏州）；颐和园、圆明园（北京）；避暑山庄（承德）

## 第二部分：园林四要素——造园的基本语言

### 一、叠山

> "虽由人作，宛自天开。"——《园冶》

叠山是中国园林独有的艺术。演变：汉代的山是"真山"（上林苑圈了一片真山）→ 魏晋开始模拟真山 → 宋代开始"写意"山（太湖石取代真山石）→ 明清叠山成为独立艺术门类。

**核心原则**："有真为假，做假成真"；太湖石：瘦、皱、漏、透；环秀山庄假山（戈裕良叠）被公认为"中国假山之冠"。

### 二、理水

> "水随山转，山因水活。"——陈从周《说园》

演变：先秦灵沼 → 汉代一池三山 → 魏晋注意水的自然形态 → 宋明在极小空间中创造丰富水面变化。

**核心原则**：聚散（水面有聚有散）、曲直（岸线要曲折）、动静（静水为主动水为辅）、"可望、可游、可居"。

### 三、建筑

> "凡园圃立基，定厅堂为主。"——《园冶》

中国园林的建筑不是"盖在园子里的房子"，而是空间骨架和视点。详见本手册《园林建筑》篇。

类型：亭、台、楼、阁、轩、榭、舫、廊、桥、墙。

### 四、花木

> "春见山容，夏见山气，秋见山情，冬见山骨。"——陈从周《说园》

花木是园林中唯一有生命的元素。演变：先秦自然生长 → 汉代有意识种植 → 魏晋花木具有人格含义 → 明清"无竹不园"成为共识。

**经典人格植物**：松（刚直）、竹（虚心）、梅（坚韧）、莲（清高）、柳（柔韧）、桂（高洁）。

## 第三部分：核心造园手法——《园冶》的语法体系

**借景**（"园林之最要"）——破除物理边界。远借（拙政园借北寺塔）、邻借（沧浪亭借园外河景）、仰借、俯借、应时而借（春桃夏荷秋枫冬梅）。

**障景**——视线遮挡，制造期待。留园入口是教科书：窄甬道→墙体遮挡→古木交柯（透一口气）→涵碧山房前豁然开朗。

**对景**——视线通道两端的互望关系。网师园月到风来亭和濯缨水阁隔水对望。

**框景**——用窗洞、门洞作为"画框"。留园石林小院四周漏窗，每窗框一峰湖石。

**漏景**——花窗使景物若隐若现。沧浪亭复廊漏窗，园内园外景观互相穿透。

**曲径通幽**——"景不藏不深，路不曲不幽。"

## 第五部分：扩展方向——园林史的横向连接

**园林与文人画**：从王维辋川别业开始，园林就成了文人画的"三维版本"。元四家、明四家的山水画构图，可以直接在苏州园林中找到对应的空间处理。

**中日园林对比**：日本园林源自中国，但在日本独立发展出了枯山水、茶庭、回游式庭园。禅宗在日本走向了极致抽象化，在中国则始终保持了"可居"的日常温度。

**中国园林对英国的影响**：18世纪"英中式园林"风潮。钱伯斯将中国造园理念带回欧洲，推动了英国自然风景园对法国几何式园林的革命。

**现代传承**：当代"海绵城市""口袋公园"的精神祖先，可在古典园林中找到。
